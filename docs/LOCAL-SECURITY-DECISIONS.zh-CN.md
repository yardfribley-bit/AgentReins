# 本机安全：用户决策与证据分层

## 页面约定

默认阅读影响和处理建议，再展开发生过程、模型正文、文件修改前后、差异与完整 JSON。保留 AI 主动检查、AI 发现以及规则审批入口。按隐私读取、接收方、命令和修改分类；分类只依据已关联事件，未解析引用的 AI 发现保留在全部发现中，不猜测分类。

## 接收地址

- 目的域名、IP、端口来自关联 GuardEvent；端点按域名、IP、端口去重，保留最新观察时间。
- 位置、ASN、组织沿用 IPGeolocationStore 缓存；没有缓存时由用户点击查询 ipwho.is。页面告知该服务会收到目标 IP，不发送任务内容。
- 不查询私网、文档保留、回环、链路本地、组播等已排除地址。查询失败不填默认位置。
- 网络组织不是服务经营者，位置不是存储地域。模型域名识别不证明最终处理服务；中转后的路径保持未知。
- 端口记录不是协议识别；22 端口不能独立证明 SSH。列表仅覆盖当前关联证据，不宣称全机或全 IP 覆盖。
- 外部服务情报未接入，不主动扫描，不展示原型中的模拟情报。

## 控制与恢复

停止入口目前提供去对应 Agent 操作的说明，不假装本页已经接入拦截。人工标记不创建放行规则。修改前内容存在不等于可安全恢复；需要校验当前版本后才能实现恢复，已发送数据不能由本机撤回。

## 性能与测试

延续最近最多 200 条证据与按 ID 查询的有界读取，不读取 Agent 原始文件，不进行全库前端聚合。IP 查询只针对点击地址。SecurityDecisionTests 覆盖端点去重、端口与服务推断边界、公网过滤及问题分类；TaskStoryVisualTests.testRenderSecurityDecision 使用非生产数据渲染真实组件。

### 2026-09-25 回归结果

- 首轮全量回归发现 IP 识别与公网查询资格混用，使保留地址在网络证据中丢失。拆分 `isIPAddress` 与 `isPublicIPAddress` 后修正，增加私网与文档地址保留测试。
- 重跑全量：283 项，277 通过、6 跳过、0 失败。跳过项需要原生渲染输出目录或本地历史 WorkBuddy fixture；安全决策组件另有显式开启的原生渲染测试通过。
- 合成测试数据：1,000 任务，20 次热查询 P95 4.16 ms；聚合 4.72 ms。100,000 事件持久化 80.38 s，数据库 190.98 MB，测试中一秒查询召回率 1.0，最大快照 68.60 ms。这不是生产端到端性能保证。
- 未完成外部服务情报接入，不把“未查到”呈现为安全。未通过本次测试验证公网查询服务实时可用性或中转后的数据去向。
