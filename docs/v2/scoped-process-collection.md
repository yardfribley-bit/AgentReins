# Agent 进程树采集（不使用 ESF）

范围：启动及每 30 秒通过 libproc 做轻量 Agent 根发现；其余轮次每 750 毫秒仅枚举已知 Agent 根及后代。低频发现用于补上后来启动或独立存在的 WorkBuddy 服务。根发现中的全机 PID/PPID 索引是临时数据，不将非 Agent 的参数与记录入库。

本次调整：
- 网络采样仅使用已归属 Agent 的 PID，避免进程快照回退时扩大为全机网络采集。
- Agent 子树中未知程序也保留观测证据，不再只用 shell/node/python 等名称白名单决定是否记录。
- 每次子树扫描通过 libproc 校验 PID 启动时间及当前可执行路径。已退出节点不再从缓存返回，PID 复用不能沿用旧 Agent 根身份；可执行路径改变时重新读取参数。
- 工具调用是语义证据，进程快照是系统观测；时间和 Agent 一致性只构成推断，不升级为确定工具归属。

边界：750 毫秒间隔内出生并退出的进程可能遗漏，低频根发现也有发现延迟。本次没有 Endpoint Security 接入，不声称全生命周期覆盖。文件和网络采样的覆盖能力亦不能由进程树范围推导。
