# AgentReins 实时生命周期测试与验收文档

版本：1.0 · 2026-10-09 · 状态：测试设计；下列计划用例尚未逐项执行

依据：[交互原型](../prototypes/lifecycle/index.html)（`2044f90`）、[开发计划](DEVELOPMENT-PLAN.zh-CN.md)、[全生命周期详细设计](LIFECYCLE-DETAILED-DESIGN.zh-CN.md)。

## 1. 验收目标与证据等级

验证用户能找到原始需求、看懂当前步骤、核对实际操作、打开交付物。分别验证“数据取得”“关联正确”“状态正确”“呈现可用”，任一失败不能以其他项通过抵消。

| 等级 | 验证对象 | 允许证明 | 不能证明 |
| --- | --- | --- | --- |
| L1 单元/契约 | 解析、去重、关联、状态归约 | 给定输入下规则正确 | 实际环境已采到 |
| L2 集成 | 采集入口→持久化→投影→页面 | 组件传递一致 | 外部Agent真实行为全部可见 |
| L3 交互/视觉 | 生产WKWebView与浏览器原型 | 点击、排版、查找、阅读 | 演示内容是真实事实 |
| L4 真实现场 | WorkBuddy/Codex新任务与证据核对 | 指定版本和来源的实际链路覆盖 | 未测来源、远端内部和任意TLS全覆盖 |

原型已有交互检查仅计L3原型验证；不将其计为生产页面或L4通过。旧版本报告需注明范围，不继承到新能力。

## 2. 环境、前置条件与样本

- 记录macOS、Agent版本、AgentReins提交/打包版本、实际运行路径、采集器版本、权限与代理状态、测试开始结束时间（Asia/Shanghai）。
- 生产实时应用与原型分开。`18953`只测试原型交互；真实采集验收使用原生应用及其真实数据入口。
- WorkBuddy/Codex各执行适用用例；不支持的能力记“不支持/缺口”，不能标通过。命令中间输出属于用户要求，缺失需保留阻断或经用户明确接受范围后调整，不自行降级验收。
- 使用隔离的临时工作目录、无密钥样本文件、本地HTTP测试服务。公网访问单独使用可控测试资源；测试报告不输出凭证或私人全文。
- 本地HTTP夹具提供200、429重试、重定向、超时、流式正文、下载和畸形JSON；它验证资源采集，但不能代替公网或TLS覆盖验证。
- 文件样本：UTF-8中文、含空格路径、Markdown/JSON、表格、大文本、版本修改、删除与移动。
- 命令样本：每秒输出一行持续5秒、交替stdout/stderr、exit 1、外层exit 0但业务失败、后台启动后最终结束、并行调用。
- Agent日志兼容样本：实际已脱敏格式、session_meta缺失片段、两种用户消息、半行、超过64KiB窗口、截断、轮换、来源代次变化。

每个场景从“确认采集器已启动→记录源水位→提交新任务”开始，验收中固定运行实例；专门的重启用例除外。

## 3. 执行与记录方法

每个表内用例的操作按其描述执行，核对源记录、标准事件、任务投影和页面四层。共享流程：

1. 建立隔离样本并记录前置状态/源能力。
2. 执行动作，记录原生session/turn/call/flow和关键事件时间。
3. 保存限定范围原始证据引用及完整性，不全库扫描或回填到生产视图。
4. 核对任务归属与状态，再通过用户操作检查页面与产物。
5. 记录实际结果、截图/事件引用、差异和缺陷编号；修复后回归。

结果只能为：未执行、通过、失败、阻塞、不适用。不适用需有能力矩阵依据；关键需求不支持属于缺口，不能用不适用规避发布门槛。

优先级：P0为链路真实性与核心用户流程；P1为完整性、排版、恢复和边界；P2为动画等优化。

## 10. 两端真实任务连续验收

每个任务带唯一验收标记，不要求真实任务一定调用全部能力；未发生环节不生成演示节点。

| 场景 | 输入/行为 | 必须核对 |
| --- | --- | --- |
| E2E-01 问候 | 简单中文问候 | 原话→可见模型边界→最终回答→原生结束，不出现假工具 |
| E2E-02 写读文件 | 指定测试目录写hello再读取并展示 | 原话→指令→调用开始/返回→文件→读取文本→最终回答 |
| E2E-03 持续命令 | 在测试目录运行逐秒输出的脚本 | 命令结束前看到真实输出，执行身份与退出码可核对 |
| E2E-04 网络报告 | 使用受控资源取数据、写报告、验证 | 实际URL/响应与连接→文件→回流→验证→产物预览 |
| E2E-05 失败重试 | 测试服务第一次429、第二次200 | 失败和第二尝试均保留，任务状态不误判 |
| E2E-06 多任务 | 两个会话同时执行不同输出命令 | 不串原话/调用/产物，阅读不被抢 |
| E2E-07 审批/取消 | 在支持来源走原生请求与确认 | 用户操作、控制确认与实际执行/停止相符 |
| E2E-08 中断恢复 | 运行中重启采集或短暂断源 | 起点连续性、缺口、恢复、不重复计量 |

两端分别填写实际证据；不以WorkBuddy一例通过替代Codex，也不以Codex源日志存在替代页面可找到。
