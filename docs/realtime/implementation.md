# AgentReins 实时工作台

本实现沿用 `docs/prototypes/realtime` 已确认原型的布局、深色样式、蜘蛛图和四列看板。生产页面位于 `Sources/AgentReins/Resources/RealtimeWorkspace`，由原生 WKWebView 加载；不包含模拟任务或演示操作。

## 范围

- 采集现场：来源记录、采集健康状态、进程观察、本地保存异常及缺少任务标识的记录。
- 任务过程：用户需求、模型交互、命令、Skill、MCP、文件和网站的已观测证据；点击节点展开输入、结果和来源。
- 结果看板：待执行、执行中、需要关注、已返回结果；支持类型筛选、证据详情和定位过程。返回结果不等同于需求验收通过。
- 支持 WorkBuddy / Codex 切换、跟随最新任务、选择本次运行的其他任务、暂停画面和恢复最新画面。暂停不停止采集。

## 实时边界

启动以后台文件元数据扫描建立现有日志 EOF 基线，仅采集此后新增记录。原有进程、文件、网络、Hook 与实时记忆采集独立保留；继承核对见 `technical-continuity.md`。实时模式跳过历史回填、历史搜索索引和语义分析，不启动历史上传。原始采集证据仍写入本地证据库，供当前证据核对；不提供历史浏览或 SessionLens 集成。

任务轮次关联要求 Agent、会话和轮次标识；缺少轮次的原生 Hook 作为会话级活动显示。原生 Agent+session+call 仅在对应轮次唯一时合并，多义时不选择。缺少任务标识的进程、文件、网络证据在采集现场单独显示，不按时间猜测归属。未知工具不会自动命名为 MCP。失败、取消、等待授权和未观测返回均分别显示。

正文每字段预览最多 16,000 字符；当前运行内存缓存最多 6,000 条 / 32 MiB，达到限制会明确提示覆盖截断。图中关系只表达已确认的调用或任务成员关系，不展示无法采集的模型内部推理。

Codex 来源是本地 rollout 日志的兼容解析，不保证完整模型 HTTP 正文。WorkBuddy 模型正文依赖已配置的网络采集路径；进程轮询也可能错过极短生命周期进程。未覆盖的数据会显示未采集，不填充示例。完整双端真实任务链路仍需现场验收。

## 运行与验证

运行 `bash scripts/package_realtime.sh`，生成 `.build/realtime-preview/AgentReins Realtime.app`。独立 bundle ID，不替换 `/Applications/AgentReins.app`。打开预览版后提交新的 WorkBuddy / Codex 任务以观察实时记录。

2026-10-09 验证：

- 相关 Swift 回归 70 项，1 项跳过，0 失败，包含原生 WKWebView、任务隔离、结果配对、输入转义、EOF 基线和缓存截断。
- 生产页面浏览器检查：三视图切换、四列看板、暂停后保持旧画面、恢复最新数据；无 JavaScript 错误。
- Swift 三个产品构建完成，独立 App ad-hoc 签名和严格签名校验通过。

截图验证使用隔离测试数据，不代表实际采集覆盖率。
