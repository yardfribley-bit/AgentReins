# AgentReins 逐项可执行测试用例

版本：2.0 · 2026-10-09 · 所有用例初始结果均为未执行。

主方案：[测试与验收方案](TEST-PLAN.zh-CN.md)；固定环境/命令：[连续验收手册](TEST-E2E-RUNBOOK.zh-CN.md)。以下每项继承P-EVIDENCE及主方案判定合同，不继承通过结果。

LIVE=P-LIVE；LAB=P-LIVE+P-LAB；REPLAY=P-REPLAY；CONTROL=P-LIVE+P-CONTROL；PUBLIC=P-LIVE+P-PUBLIC。缺前置能力即阻塞并登记具体缺口。

公共收尾C0：保存O/S/E/P/U引用与结果；停止仅本用例启动的夹具进程；恢复原采集/权限配置并核对。保留测试目录，不删除证据、不终止用户业务进程。注入只在测试目标，绝不写生产日志。

## CAP-01 · 两端分别提交一句含唯一标记的中文需求

- 优先级：P0；前置：LIVE、P-EVIDENCE；适用来源按主方案追踪表逐端记录。
- 样本/输入：发送原话：RUN_ID 请原样回复“你好，采集验收”。保存submitted.txt。
- 操作步骤：
  1. 确认前置、分配新RUN_ID；记录版本、起点水位及样本哈希。
  2. 在Agent源记录找该消息；核对E/P身份；在任务卡和原话面板分别查看。
  3. 将结果逐项与独立基准及主方案断言对照，记录差异，不以截图内容生成基准。
- 通过断言：A-TEXT、A-ID；完整正文逐字符比对，标题可截短。
- 业务预期：源原文、事件原文、任务正文一致；不能用短标题替代
- 必留证据：输入/夹具版本、源记录定位、标准事件ID、投影版本和身份/状态、对应界面截图或录屏；无UI的L1用例留断言日志并在报告明确等级。
- 恢复：C0。涉及重启/断源/端口占用时额外确认所有原采集源恢复。
