## 本次修复及回归

1. 外网任务入口只列出当前有已采网络证据的任务，分别显示数据交互和连接观察数量；保留无证据任务数量说明。
2. 无证据任务明确说明不能判断外联或安全，提供返回已有证据任务的入口。
3. 修复待关联交互点击后不能打开详情；详情明确“不属于已确认当前任务”，不计入该任务步骤。
4. 任务入口保留 Agent 与任务标题筛选。

## 必须补齐的验收阻塞项

- Codex 实际外联到正文证据再到任务页面的链路尚未闭环。
- 不能用工具参数、命令输出或连接采样替代实际网络发送/返回。
- 当前仍有容量截断和重启来源缺口提示，不能作完整审计结论。
- 直连、代理、子进程、SSH/Git 的真实覆盖矩阵必须逐项实测；未采内容要说明具体来源和原因。
- 全量正文保留与按需查看须独立核验，16k 预览不是完整正文交付。
- 安全规则命中、漏报、误报与自然语言规则执行仍需独立验收。
