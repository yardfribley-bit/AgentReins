# 实时动态图与点击详情

任务过程默认展示用户、上下文、模型、Agent、工具及已采到的进程、文件、网络关系。当前等待模型或工具返回的节点高亮；底部用文字说明当前阶段与已采数据数量。工具预览显示最新四项，完整采集记录仍在采集现场。

节点及连线均可点击。右侧显示实际输入、输出、上下文组成、来源、证据编号与关联依据。点击后固定详情快照并退出任务自动跟随；新事件继续更新主图，不替换正在阅读的内容。可从任务选择器恢复跟随最新任务。

首次加载不补播动画；只有新记录到达时沿对应连线播放一次短动画。暂停画面时不播放。工具返回显示回程方向，已匹配的工具结果显示进入模型上下文的关系。独立进程、文件与网络观察用虚线表示，不能把同时出现误称为具体工具执行者。

沿用现有采集器，不更换进程、文件、网络、Hook或模型采集，不回填历史。原始证据保留在既有本地证据库。

## 验证

33项相关Swift测试通过，包括生产WebKit渲染。Chrome交互检查通过：默认动态图、节点与连线详情、上下文块切换、详情阅读固定、当前工具等待状态、有限动画以及采集/结果视图。视觉与交互测试使用隔离测试数据；真实工具全链路仍需新任务现场验收。
