## 已实现

- 按浅色交互原型实现原生实时工作台：采集现场、任务过程、结果看板；不载入历史任务。
- 任务使用 Agent／会话／轮次身份隔离；工具返回仅凭原生调用身份配对，歧义保留为独立观察。
- 生命周期阶段、当前步骤、采集覆盖率来自后端证据投影。进行中、等待确认、完成未读、失败分别归类；取消及状态未确认单独列出。
- 普通模型消息完成及单个工具成功不代表任务完成。单个工具失败保留错误，等待 Agent 后续动作；原生任务结束记录才驱动终态。
- 动态图节点与连线可点开。原始需求、上下文块、模型往返、调度、命令、MCP／Skill、文件及网络使用对应详情。阅读对象固定，增量内容提示更新。
- 原始 WorkBuddy 用户输入不再截到 1,000 字符；缺少原话明确显示缺口，不拼接继承字段作为需求。
- Codex 增量解析保存跨轮询身份、半行及 UTF-8 续读、调用配对；原子轮换及截断重置身份；原生命令结构保存参数、输出、时长、退出码。只在来源有输出增量时显示时间线。
- 复用原有进程、文件、网络、Hook 与 HTTPS 请求正文采集。网络详情补 HTTP 方法和响应状态；沿用 IP 地理／ASN 缓存与主动查询，显示来源及时间，查询失败可见。
- 产物只从已关联的实际写入／明确工具结果提取；本机异步核对文件存在、大小及文本预览。原生桥接只接受已知任务和产物 ID；脚本／HTML 不自动打开。
- 已采活跃任务与 Codex 实时游标各有原子检查点（0600）。正常退出刷盘；游标恢复校验文件身份及末尾锚点，从已采偏移续读，不回填旧日志。

- 活跃检查点上限 8 MiB，内存证据上限 32 MiB／6,000 条；达到上限显示截断或保存失败。大任务与强制杀进程的连续性不能无条件保证。
- 重启校验发现源替换／截断／锚点变化时保留采集缺口，从当前末尾采集；不会伪造缺失需求。
- IP 查询是第三方估计，不是服务器精确物理位置。没有资源 URL 或正文的系统连接仍按连接证据展示。
- 原生桥接目前支持已知产物打开、标记已读、重新核对文件、查询已观察 IP。停止 Agent、行内反馈续跑、Office 内嵌预览尚未实现；界面不提供虚假的成功动作。
