# AgentReins 生命周期交互原型

设计稿，全部为明确标注的演示数据，不连接生产采集器、不执行示例命令、不访问示例API。

本机预览：`python3 -m http.server 18953 --bind 127.0.0.1 --directory docs/prototypes/lifecycle`

打开 http://127.0.0.1:18953/ 。浅色暖灰布局参考用户给出的任务看板截图。

## 查看顺序

1. 默认天气任务：顶部原话和当前动作，中央关系图，右侧命令执行面板。
2. 点击生命周期入口、图节点或连线：查看原话、环境、模型上下文/变化、工具指令、计划、执行、Skill/MCP、文件、网络、失败、回流、验证、产物的不同排版。
3. “演示下一步”：限流与重试 → 数据返回与报告生成 → 验证 → 交付。详情阅读对象固定；重新点击可读更新后的内容。
4. 结果看板：四种任务状态，点击卡片定位执行、审批、错误或产物。
5. 采集现场：来源、覆盖、应用进程及未关联活动；演示记录点击回到对应天气任务。
6. 左侧任务切换：待授权、完成周报、端口占用失败等场景。

命令复制会请求浏览器剪贴板权限；其他交互只改变原型内状态。授权/拒绝按钮仅演示，不向外部Agent发送控制请求。IP、域名、归属和天气为示例，不能用作真实采集或真实查询结果。

## 已做验证

真实浏览器检查：十二环节点击、详情固定、失败重试、资源与IP字段、文件内容切换、产物预览、四列看板、审批、来源跳转、1024/736/390宽度无页面横向溢出。手动查看命令、网络、看板截图并修正图连线缩放。

这证明原型可交互，不证明生产采集链路已经完成。生产实现必须遵循 PRODUCT-TECHNICAL-DESIGN.zh-CN.md 与 LIFECYCLE-DETAILED-DESIGN.zh-CN.md 的来源和验收契约。
