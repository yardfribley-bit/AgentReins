# AgentReins 实时工作台原型

分支：`codex/agentreins-realtime-visualization`。

本轮交付为可交互界面原型，不是生产采集实现。打开 `index.html`，无需网络依赖。

- 采集现场：来源 → 协调器 → 本地证据库／任务投影。
- 任务过程：需求、Agent、模型、Skill、MCP、命令、文件、网站的关系图。
- 结果看板：逐项核对用户要求、文件变更、测试结果和未验证项。
- 三个视角共享同一模拟任务；支持切换 Agent、点击节点、演示推进、结果定位过程。
- 暂停仅冻结画面概念；没有启动真实采集器。所有数字和内容为明确标注的模拟数据。
- 只设计当前任务增量与任务结束时的交付视图；不包含历史扫描、回填、历史搜索或长期分析。
- 当前未修改生产程序，未替换本机安装包。实际 WorkBuddy／Codex 的采集能力须逐来源接入和验收，原型不证明完整覆盖。

设计方向：深色工作台，薄结构线、稳定布局、内容优先的节点与证据检查器。后续实际数据动画只由真实新增事件驱动。

本轮浏览器验证：三个视角切换、节点详情、Agent 切换、暂停、任务结束、结果跳转证据、390px 无横向溢出均通过；浏览器无脚本错误。三张 PNG 为真实浏览器渲染的原型截图，非生产采集截图。

## 2026-10-09 状态看板调整

按用户提供的参考，结果页改成当前任务的状态看板：待执行、执行中、需要关注、已返回结果。每张卡片包含动作、状态原因、实际结果／等待条件、时间和证据入口。需要关注中分别标注执行失败、等待授权、采集缺口和采集延迟；不以一个红灯替代原因。

支持类型筛选、点击卡片展开详情、从详情定位执行过程、模拟 Agent 最终回复后自动移动卡片，以及测试通过／测试失败／采集延迟三种演示场景。状态由演示事件推进，无手动完成或拖动覆盖状态。页面没有启动真实任务，也不发起授权操作。
