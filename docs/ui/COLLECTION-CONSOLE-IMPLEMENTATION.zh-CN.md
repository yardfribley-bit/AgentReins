# 采集现场：按已确认原型实现

参考原型：agentreins-collection-content.html。只调整 macOS AgentReins 的采集界面，不接入 AppLens，不改变 WorkBuddy 执行行为。

## 结构

- 动态进程树：PID 加启动时间区分身份，新进程自动加入，离开树后保留节点；按启动参数提供候选职责，点击查看依据。隔离状态未接入，不推断为沙盒。
- 采集管道：进程观察、原生 Hook、HTTPS 正文、本地日志等来源；新收到的记录驱动流动动画。显示接收、识别、关联、保存四个位置；没有接口的队列和单条保存状态标记未接入。
- 内容摘要：先看具体内容，按需展开来源、调用编号、关联依据与原文预览。工具请求与结果只按会话和调用编号配对；无 PID 的正文不强行挂到进程。
- 回放：本页最近 60 个不可变采集快照，暂停、按快照调速、拖动、回到实时。进入回放时冻结快照窗口，后台采集继续；页面销毁或应用重启后窗口重置。

## 性能与证据边界

UI 缓存至多 500 个有界摘要，快照展示约 40 个代表记录。正文每字段预览最多 2,000 字符；超过 1 MB 的上下文不在前端重新解析。高频资源样本不会立即挤掉其他类型的代表记录。原始证据的保留和落库沿用原采集链路，本页收到投影不等于全部保存成功。

进程快照缺失不代表确认退出；文件句柄不代表读过全文；资源指标不代表内存内容；可见 reasoning 不代表未返回的内部思考。极短进程的现有漏采没有通过此界面修改解决。

## 验证

编译和应用打包、签名验证通过。相关进程树、摘要、网络、Hook 测试通过；最后追加工具配对测试验证跨调用不误关联。尚未完成实际应用界面的视觉验收。历史数据库回放、队列和单条保存时间不是本轮已实现能力。
